プライバシーポリシー

制定日：2026年10月26日

「かぶ発見ラボ 投稿ツール」（以下「本ツール」）は、YouTubeチャンネル「かぶ発見ラボ」の運営者が自分のチャンネルを管理するための個人用ツールです。本ツールはYouTube API Servicesを利用しています。

利用規約とGoogleのプライバシーポリシー

本ツールを利用する場合、YouTube利用規約に同意したものとみなされます。YouTube API Servicesによる情報の取扱いには、Googleプライバシーポリシーが適用されます。

取得する情報

本ツールは、利用者がGoogleアカウントで許可した範囲で、YouTube API Servicesから次の情報を取得します。

  • 認証したYouTubeチャンネルの情報（チャンネルIDなど）
  • 本ツールで投稿した動画の情報（動画ID、タイトル、概要欄、公開状態、処理状態など）
  • APIを利用するための認証情報（アクセストークン、リフレッシュトークン）

利用目的

取得した情報は、運営者自身のチャンネルへの動画のアップロード、サムネイルの設定、公開・予約公開、投稿状態の確認のためだけに使います。

保存

認証情報と投稿結果は、運営者が管理するサーバー上に、運営者のみが読み書きできる設定で保存します。

第三者への提供

取得した情報を第三者へ提供・販売することはありません。

Cookieなど

本ツールは、利用者の端末にCookieなどの情報を保存したり、端末から情報を読み取ったりしません。

アクセス権の取消しと削除

本ツールへのアクセス許可は、Googleアカウントのセキュリティ設定ページからいつでも取り消せます。取り消した場合、保存している認証情報は使用できなくなり、運営者が削除します。

お問い合わせ

本ポリシーに関するお問い合わせは、YouTubeチャンネル「かぶ発見ラボ」までお寄せください。
